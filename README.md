# Smart Legal Assistant

This is an AI-powered legal toolkit for legal analysis, document generation, and independent external-document citation checking:

1. 智能裁判分析與比對 (Smart Appeal Assistant / Judgment Analysis)
2. 證據清單與時序生成 (Evidence List Generator)
3. 爭點整理表格生成 (Issue Table Generator)
4. 實務見解與判例檢索 (Judgment Search Tool)
5. 司法院資料開放平台連線 (Judicial OpenData Tool)
6. 外部法律文件 AI 檢核器 (External Legal Document Checker)

## 啟動方式
npm run dev

## 測試指令
npm run test:eval
